## 📖 Miniguia Estruturado

### 🔹 Introdução

Os juros compostos representam o crescimento exponencial do capital ao longo do tempo, pois os juros incidem sobre o valor inicial acrescido dos juros acumulados anteriormente.

### 🔹 Fundamentos Matemáticos

```
M = C (1 + i)^t
```

Onde:
- M = Montante
- C = Capital inicial
- i = Taxa de juros
- t = Tempo

### 🔹 Aplicação Prática

```
M = 1000 (1,10)^3
M ≈ R$1.331
```

Exemplo: investimento de R$1.000 a 10% ao ano por 3 anos.

## 🧠 Glossário

- Selic: Taxa básica de juros da economia.
- CDI: Taxa de referência para renda fixa.
- IPCA: Índice oficial de inflação.
- Montante: Valor final acumulado.
- Capitalização: Juros sobre juros.
